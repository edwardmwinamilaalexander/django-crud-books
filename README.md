📚 Django Bookstore App
A clean and modern Django CRUD application for managing books with image uploads, Bootstrap UI, and a responsive layout.

🚀 Features
Feature	Description
```
📚 Book List	View all books with images
➕ Add Book	Upload image + title + description + price
✏ Update Book	Edit existing book details
❌ Delete Book	Confirmation page before deletion
🖼 Image Uploads	Stored in /media/
🎨 Bootstrap UI	Clean, responsive layout
```
